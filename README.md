## 📖 Overview

**Devendar.ai** is the official engineering portfolio of **Devendar Kumavat**, a Generative AI & Machine Learning Engineer specializing in **RAG Pipelines, Computer Vision (`YOLOv8`, `CNN`), NLP, and scalable `FastAPI` microservices**.

Designed with a dark glassmorphism aesthetic (`#030305` base with `#00f2fe` cyan accents), the portfolio features biometric scanner animations, cursor-tracking radial spotlight cards, auto-discovering multi-image project carousels, hologram certificate previews, and an interactive AI terminal contact assistant (`DEV_AI_ASSISTANT v2.0`).

---

## ✨ UI/UX Engineering & Interactive Features

* **🎯 Biometric HUD Scanner & Typewriter Hero:** Features a dual-ring rotating HUD, a vertical cyan laser color-wipe scanner over the profile portrait, corner bounding-box locks, a real-time cycling telemetry readout (`[SCANNING_BIOMETRICS]`, `FAST_API_SERVER: [200_OK]`), and an automated typewriter engine.
* **🔦 Cursor-Tracking Flashlight Glow:** Tracks real-time mouse coordinates (`--mouse-x`, `--mouse-y`) across all glassmorphism cards to render a dynamic `450px` radial cyan spotlight effect on hover[cite: 36].
* **🎞️ Auto-Discovering Crossfade Project Sliders:** Dynamically probes and loads sequential project screenshots (`images/<prefix>1.png` / `.jpg`, `2.png`, etc.) without hardcoded image arrays, complete with 3.8-second auto-play, manual navigation controls, and smooth cubic-bezier zoom/crossfade transitions[cite: 36].
* **🤖 Interactive AI Terminal Contact Assistant (`DEV_AI_ASSISTANT v2.0`):** Uses `IntersectionObserver` to trigger a simulated multi-message bot greeting sequence when scrolled into view, and transmits form payloads asynchronously via the **FormSubmit AJAX API** with live chat bubble updates[cite: 36].
* **🎓 Hologram Certificate Previews:** Academic and professional credential cards feature floating `HOVER_TO_PREVIEW` tooltips that reveal high-resolution certificate scans on hover[cite: 36].
* **♾️ Infinite Kinetic Typography Marquee:** Multi-track, bi-directional CSS stroke-text marquees scrolling behind the technical skills arsenal[cite: 36].

* **Typography & Icons:** Google Fonts (`Inter` & `Fira Code` monospace), SimpleIcons CDN, Custom Inline SVGs[cite: 36]
* **Interactivity & APIs:** Vanilla JavaScript (ES6+), `IntersectionObserver` API, Dynamic Image Preloader, FormSubmit AJAX API[cite: 36]
